## 9. Prioritised migration waves

### Wave A — Finish active workspace visual proof
- **Scope:** Capture 390/430/768/1440 screenshots of the migrated
  `ShellHostComponent` (Wave 2.1) and Foundation overview (Wave 2.2).
- **Files / classes:** `products/shahin-ai/app/src/app/blueprint/core/platform/shell/shell-host.component.ts`, `platform/foundation/ui/pages/foundation-overview.component.ts`.
- **Acceptance:** No horizontal overflow; account menu does not cover title;
  bottom nav does not hide content; no overlapping FABs; RTL alignment clean.
- **Validation commands:** `pnpm --filter shahin-ai-grc-frontend start`, then
  Playwright screenshots at the four breakpoints.
- **Visual proof:** four PNGs committed under
  `platform/docs/ui/visual-proof/wave-a/`.
- **Rollback:** none required (capture-only).

### Wave B — Foundation overview complete adoption
- **Scope:** Migrate remaining Foundation overview slots (action-bar →
  `DosAdaptiveCommandBar`, status banners → `DosStatusBanner`, empty/loading
  states → `DosEmptyState` / `DosLoadingState`).
- **Files:** `platform/foundation/ui/pages/foundation-overview.component.ts`.
- **Acceptance:** No `LEGACY_DUPLICATE` rows remain in
  `platform/foundation/ui/pages/foundation-overview.component.ts`; ui-os:guards
  green; Foundation overview renders in mobile + desktop.
- **Validation:** `pnpm --filter @dos/ui-system build`, frontend build,
  ui-os:guards.
- **Visual proof:** Wave A screenshots refreshed.
- **Rollback:** revert single commit.

### Wave C — Register 14 domain widgets in Dynamic UI
- **Scope:** Add the 4 missing registry entries (§4 / §8); align the 3 risk
  heatmap variants under a single `Risk.RiskHeatmap` canonical renderer;
  decide canonical compliance heatmap; activate runtime allowlist gate.
- **Files:** `platform/ui-system/dos-ui-contracts/src/capability-registry.ts`, the
  Dynamic UI render switch.
- **Acceptance:** Every domain-widget render goes through
  `isAllowedComponentKey(...)`; CI guard fails on any unknown key.
- **Validation:** `pnpm --filter @dos/ui-contracts build`, ui-os:guards,
  frontend build.
- **Visual proof:** Risk heatmap + compliance heatmap renders unchanged.
- **Rollback:** flag-toggle in registry.

### Wave D — Migrate top 25 legacy duplicate shared UI components
- **Scope:** P0 batch (§2 rows 1–18) plus P1 (§3 rows 1–4), rolled out in
  three commits: shell drawers, website shell, Foundation dialogs.
- **Acceptance:** All migrated rows disappear from the
  `LEGACY_DUPLICATE` count on next census run (drop ≥18). No new raw-CSS or
  RTL-physical violations.
- **Validation:** frontend + website + module builds, ui-os:guards.
- **Visual proof:** screenshots at the four breakpoints for each migrated
  page.
- **Rollback:** per-commit revert; old components are not deleted in this
