## 🗂️ FILE STRUCTURE PER COUNTRY

Each country folder contains 4 CSV files:

### 1. `country.csv`
Country profile with code, name (EN/AR), region, currency, capital, timezone, population, GDP

### 2. `regulators.csv`
```
code, name_en, name_ar, country_code, category, jurisdiction_en, website, established_year
```

### 3. `frameworks.csv`
```
code, name_en, name_ar, country_code, regulator_code, category,
is_mandatory, version, total_controls, total_domains, domains
```

### 4. `controls.csv`
```
id, country_code, framework_code, version, control_number, domain,
title_en, title_ar, requirement_en, requirement_ar, control_type,
maturity_level, priority, is_mandatory, evidence_types, status
```

## 🚀 USAGE

### Load Single Country (e.g., UAE):
```bash
psql -d grc_db -c "\copy regulators FROM 'gcc/UAE/regulators.csv' CSV HEADER"
psql -d grc_db -c "\copy frameworks FROM 'gcc/UAE/frameworks.csv' CSV HEADER"
psql -d grc_db -c "\copy controls FROM 'gcc/UAE/controls.csv' CSV HEADER"
```

### Load All GCC:
```bash
for country in UAE BAHRAIN KUWAIT OMAN QATAR; do
  psql -d grc_db -c "\copy regulators FROM 'gcc/$country/regulators.csv' CSV HEADER"
  psql -d grc_db -c "\copy frameworks FROM 'gcc/$country/frameworks.csv' CSV HEADER"
  psql -d grc_db -c "\copy controls FROM 'gcc/$country/controls.csv' CSV HEADER"
done
```

### Load All G20:
```bash
for country in $(ls g20/); do
  psql -d grc_db -c "\copy regulators FROM 'g20/$country/regulators.csv' CSV HEADER"
  psql -d grc_db -c "\copy frameworks FROM 'g20/$country/frameworks.csv' CSV HEADER"
  psql -d grc_db -c "\copy controls FROM 'g20/$country/controls.csv' CSV HEADER"
done
```
