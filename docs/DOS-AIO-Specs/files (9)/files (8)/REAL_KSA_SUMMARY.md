## 🔗 USAGE: SQL QUERIES

### Q1: All real KSA controls with their evidence
```sql
SELECT 
    c.framework_code,
    c.regulator,
    c.control_number,
    c.title_en,
    c.title_ar,
    c.priority,
    STRING_AGG(em.evidence_type_code, ', ') AS evidence_required
FROM controls c
LEFT JOIN evidence_mapping em ON c.control_id = em.control_id
WHERE em.is_mandatory = true
GROUP BY c.control_id, c.framework_code, c.regulator, c.control_number, c.title_en, c.title_ar, c.priority
ORDER BY c.framework_code, c.control_number;
```

### Q2: SAMA controls with 4-hour notification requirement
```sql
SELECT control_number, title_en, requirement_en
FROM controls
WHERE framework_code = 'SAMA-CSF'
  AND requirement_en LIKE '%4 hours%';
```

### Q3: PDPL controls with critical residual risk
```sql
SELECT 
    c.control_number AS article,
    c.title_en,
    r.inherent_risk_score,
    r.residual_risk_score,
    r.risk_treatment
FROM controls c
JOIN risk_assessment r ON c.control_id = r.control_id
WHERE c.framework_code = 'PDPL'
  AND r.residual_risk_level IN ('high', 'critical')
ORDER BY r.residual_risk_score DESC;
```

### Q4: Evidence required for KSA cross-border data transfer
```sql
SELECT 
    em.control_number,
    em.evidence_type_code,
    em.evidence_name_en,
    em.min_retention_months,
    em.approval_role
FROM evidence_mapping em
JOIN controls c ON em.control_id = c.control_id
WHERE c.framework_code = 'PDPL'
  AND c.subdomain_code LIKE '4-%';
```
