# 13 — Competitive positioning and differentiators

**Evidence-first.** **Dogan Consult** · **Dogan-AI OS** · **Shahin-AI**

## Differentiators supported by repository structure

1. **Explicit modular registry** — 72 modules + 37 services in JSON registries (committed).  
2. **Monorepo + pnpm** — shared packages and multiple surfaces (`pnpm-workspace.yaml`).  
3. **Thin default runtime, thick catalog** — 4 PM2 apps vs large `DOS Platform/` tree clarifies **platform vs demo slice** story for sophisticated buyers.  
4. **Branded product example** — Shahin-AI Website assets and PWA manifest tie product to **Dogan Consult**.
